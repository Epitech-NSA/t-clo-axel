## Différence entre Guides, Runbooks et Operations

| Type | Description | Utilisation |
|------|-------------|-------------|
| **Guides** | Introduction et utilisation | Apprendre |
| **Runbooks** | Procédures opérationnelles | Déployer |
| **Operations** | Référence technique | Gérer au quotidien |

**Exemple**:
- **Guide**: "Comment démarrer avec TERRACLOUD"
- **Runbook**: "Procédure de déploiement PaaS en 10 étapes"
- **Operations**: "Référence des commandes Make"
